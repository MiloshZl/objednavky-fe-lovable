# Mobilní UX specifikace

## 1. Primární flow
1. Přihlášení přes login + token
2. Denní přehled po přihlášení
3. Přepínání mezi terapeutkami nebo oběma pohledy
4. Výběr dne a zobrazení rezervací a volných slotů
5. Vytvoření nebo úprava rezervace

## 2. Hlavní obrazovky
- dashboard / denní přehled
- detail rezervace
- vyhledání nejbližšího volného termínu
- pacient detail
- admin přehled aktivních zařízení
- audit historie

## 3. UX principy
- maximálně 2-3 kroky pro časté akce
- velké touch cíle
- jasné statusy: active, excused, cancelled
- varování na sedmou návštěvu je informativní, neblokující
- rezervace se zadávají na 15min startovém kroku

## 4. Mobile constraints
- odlehčený design, snadné zobrazení na iPhone
- kratší formuláře a minimum vstupů
- rychlé filtrování dat podle dne, terapeutky a stavu
- přehledné rozložení pro jednouživatelské workflow
